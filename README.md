# Herramientas que faltan

Recopilación de herramientas que la gente pide y todavía no existen (o no existen bien): ideas surgidas de Hacker News, dev.to, ProductList y la semana de construcción de Somebody Build This (21–23 de noviembre de 2026), con enlaces a las fuentes originales de cada pedido.

## Cómo verla

Es una página **estática** (un solo archivo HTML, sin servidor ni base de datos):

- **En local:** abrí `index.html` en cualquier navegador moderno, o servila con `python3 -m http.server` y entrá a `http://localhost:8000`.
- **En GitHub Pages:** subí el contenido de esta carpeta a un repositorio y activá Pages (rama principal, carpeta raíz). La página queda en `https://<usuario>.github.io/<repo>/`.

## Notas

- No necesita internet para leerse: todo el contenido está dentro del archivo. Los enlaces a las fuentes (ProductList, dev.to, Hacker News, Somebody Build This, etc.) sí necesitan conexión, como cualquier enlace externo.
- Investigación realizada el 24 de noviembre de 2026 sobre fuentes fechadas principalmente entre el 21 y el 23 de noviembre de 2026.
